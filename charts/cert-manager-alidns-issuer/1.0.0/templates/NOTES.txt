This release creates ClusterIssuer {{ .Values.issuer.name }} and no workloads.

Check account registration:
  kubectl get clusterissuer {{ .Values.issuer.name }}

AliDNS credentials must exist in cert-manager's cluster resource namespace:
  Secret: {{ .Values.alidns.existingSecret }}
  AccessKey ID key: ACCESS_TOKEN
  AccessKey Secret key: SECRET_KEY

The AliDNS webhook must already use groupName {{ .Values.webhook.groupName }}.
cert-manager creates the ACME account Secret automatically:
  {{ .Values.issuer.name }}-production-account-key

Let's Encrypt production is always used.

Applications select ClusterIssuer {{ .Values.issuer.name }} in their certificate
settings, or use the annotation cert-manager.io/cluster-issuer on an Ingress
with spec.tls. VPN applications keep ingressClassName: traefik-vpn.

Ready confirms ACME account registration. Request an actual certificate to
verify DNS credentials, webhook configuration, and DNS-01 validation.
