Magpie runs one persistent gateway with its Web UI on port 3430.

For private setup:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "magpie.fullname" . }} 3430:3430

Open http://localhost:3430/?k=<your-web-key> in a trusted browser.
The key is read from Secret {{ include "magpie.secretName" . }}, key {{ ternary "MAGPIE_WEB_KEY" .Values.auth.secretKey (not (empty .Values.magpie.envSecret)) }}.
Restart the Deployment after updating an existing Secret to reload its environment variables.

Add providers and sign-ins in the Web UI, then create gateway keys for API clients.
The Web administration key is separate from gateway API keys.
Use HTTPS or a private tunnel for remote administration.
The config PVC is retained on uninstall; back it up and manage it separately.
